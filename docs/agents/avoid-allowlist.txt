# Accepted hits for the GLOSSARY `_Avoid_` sweep in scripts/check-crosslinks.sh (warning-only).
# One entry per line: `term` allows the word everywhere; `term @ <path-glob>` allows it in the
# files the glob matches; `* @ <path-glob>` allows every term there. Terms match whole words,
# case-insensitively, with a hyphen counted as part of the word. `#` starts a comment.
#
# A term goes here for one of three reasons, and the reason is written next to it: it is
# ordinary English that no Relay sense can own; the `_Avoid_` line rejects it only in a sense a
# word-grep cannot see (its qualifier names the sense, and the hits are the other one); or the
# hit is a historical note that names the old word to record the rename. Terms that are also
# glossary headwords (`**Policy**:`, `**Task**:`) are never swept and need no entry here.
#
# Seeded 2026-09-21 from the first run over docs/specs/, AGENTS.md, README.md and GLOSSARY.md.
# A hit that is real drift stays a warning: fix the prose, do not add it here.
