## Intent

Today a Relay host is configured by `RELAY_*` environment variables and flags that systemd hands
it. A Node is configured by a hand-couriered CA bundle and a token. Neither has a package. This
milestone does four things:

- The Relay reads one root-set TOML file, and refuses to run if it could write that file or
  anyone else could read it (gap row 11 closes).
- A Node joins with one pasted value, which pins the Relay's CA.
- Both binaries ship as reproducible `.deb`/`.rpm` packages, proven on every supported platform
  by CI.
- `relay init` replaces the two bootstrap verbs.

## Shape

### Seams that do not move

- **`newServer(Config)` / `newServerWithHooks`** stays the composition root's one entry point.
  The new loader *produces* a `Config`, so every e2e test that builds a `Config` literal keeps
  working.
- **The capability layer's adapter-facing interfaces.** No adapter gains a setter, and no route
  or tool writes configuration (RC-11, RC-32). The layer's *construction* does change: see S10's
  contract change below.
- **`Enrollment.Enroll`** and every Node-plane RPC. The join string only changes what the daemon
  trusts *before* it sends the token.
- **The daemon's Policy and Template loaders** and their mode refusals (DI-12, DI-20). Packages
  decide what is *placed*, never what the daemon *does* (ADR-0033 decision 4).
- **The release's binary build:** two passes, a byte comparison, static guards, cosign keyless.
  Packaging sits downstream and never rebuilds a binary.

### Key designs

**The join string (S1, S4, S6).**
- **Pinned:** SHA-256 over the CA certificate's DER (`ca.Fingerprint`, the number `relay init`
  and the Console show).
- **Presented:** the CA certificate in the TLS chain. Today the Relay presents the leaf only,
  which is why S4 exists.
- **Sent before verification:** nothing. The token leaves only after the pin matches.
- **Later starts** use `ca_bundle.pem` and the persisted address. `RELAY_ADDR` overrides the
  address. The join string is inert, so clearing it (R16's control) is safe.

**The unit guard (S6, S12).** `Restart=on-failure` stays. The clean exit 0 happens only in the
fully-unconfigured state (Question 4). Every other refusal exits non-zero and shows as failed.
No path unit and no timer exist (DI-25).

**`hostfile` (S5).**
- **Walking the path.** The walk starts from `/` and opens each component with
  `openat(dirfd, name, O_RDONLY|O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC)`, so a symlink anywhere in the
  path is refused, not just in the last component. Owner, mode and ACLs are checked on each
  ancestor's descriptor as the walk goes.
- **Sticky directories.** A sticky directory is acceptable only when its next component is owned
  by root.
- **Opening the leaf.** The leaf is opened with `O_RDONLY|O_NOFOLLOW|O_NONBLOCK|O_CLOEXEC`, so a
  FIFO cannot block, and `fstat` must report a regular file. The decision and the read use that
  same descriptor.
- **ACLs.** `system.posix_acl_access` is read with `fgetxattr` and parsed by hand (version 2;
  named user and group entries and the group-owner entry, each limited by `ACL_MASK`). An
  unknown version is refused, and so is the presence of `system.nfs4_acl` or `system.richacl`.
- **Filesystems.** `fstatfs` checks `f_type` against an allowlist: ext2/3/4, XFS, btrfs, tmpfs,
  overlayfs. Anything else is refused, which includes NFS, CIFS, FUSE and 9p. `ST_RDONLY` is
  recorded.
- **Capabilities.** The gatherer parses `CapPrm`, `CapEff` and `CapAmb` from
  `/proc/self/status`. `CAP_DAC_OVERRIDE`, `CAP_FOWNER`, `CAP_CHOWN` or `CAP_SYS_ADMIN` in any
  of them means "could write". Uid 0 is refused.
- **Generated material** (RC-17) has its own rule: owned by the Relay's uid and readable by
  nobody else.
- **Other operating systems:** refuse to start.

**The configuration file (S8, S9).**
- **Sections:** `[node_plane]` (including `advertised_address`), `[control_plane]`,
  `[console]`, `[ca]`, `[store]`, `[tls]`, `[oauth]`, `[approval]` and `[log]`, plus `[reach]`
  and `[enrollment]` for RC-22. Exact keys are decided in S8 against the example file, which the
  drift test pins to `Config`.
- **Secrets:** a secret key `x` is given as `x = "…"` or as `x_file = "/path"`. Giving both is
  refused. The webhook URL is a secret.
- **Startup order:**
  1. Refuse retired `RELAY_*` names.
  2. Open and check the file.
  3. Decode strictly.
  4. Validate.
  5. Open and check every named file.
  6. Check the state locations.
  7. Only then call `newServer`.

**Reload (S10).** SIGHUP reruns steps 2–6 and diffs the result against the running snapshot. A
changed bind-time setting, a failed check, or an invalid value refuses the whole reload; the
snapshot is untouched and the process stays up. On success it swaps one atomic snapshot, the
approval gate, and the log handler. It writes one audit record attributed to the host (the Freeze
lever's principal), naming the changed keys; secret keys appear by name only.

- **Enablement and starts.** On a first install only, and only if `/run/systemd/system` exists,
  the package runs `systemctl preset`. Nothing ever runs `start` or `restart`. An upgrade runs
  `daemon-reload` only. Remove stops and disables the unit before deleting the binary.
- **Purge.** A preinst marker records which fixed paths already existed. Purge reads only that
  marker and acts only on literal paths (DI-31, RC-26).
- **First install.** On `.deb`, preinst `install` with no old version. On `.rpm`, `$1 == 1`.
- **Relay purge** moves `/var/lib/relay` aside to a timestamped sibling, `root:root 0700`, and
  prints where it went. It never deletes the account.
- **Missing FQDN.** The hostname key is written commented out, and the Relay refuses, naming it
  (RC-19).
- **Reproducibility.** `SOURCE_DATE_EPOCH` is set to the commit time, and nfpm's `mtime` is set
  explicitly from it in every manifest. File order and modes are fixed in the manifest. The
  double build is the check.

**Catalog name binding (S2).** A committed ledger lists every released Template name with a
digest of its canonical body and risk class, computed by the daemon's own parser. Three checks
enforce it:
- A daemon test fails if any catalog name's digest differs from its ledger entry.
- A script fails if the ledger changes anything other than appending entries or marking an entry
  withdrawn, compared with the most recent release tag's ledger.
- The release workflow refuses a catalog name missing from the ledger.

Withdrawn names stay in the ledger forever.

**Key designs for S15.**
- **Containers.** Each runs with `--cgroupns=host`, a writable `/sys/fs/cgroup`, and `tmpfs`
  on `/run` and `/run/lock`. `--privileged` is used only where a distribution's systemd refuses
  without it, and the job records which rows need it.
- **Images.** UBI 10 init is the RHEL row. Every other row, Amazon Linux 2023 included (it has
  no init image), installs `systemd` into its official base image in a per-platform Dockerfile
  and execs `/usr/sbin/init`.
- **Upgrade source.** The same commit is built twice, once with a lower version (`0.0.0~matrix1`)
  and once with the real version, so the upgrade path is hermetic and needs no prior release.
  Once a release with packages exists, a second upgrade row starts from its attachments.
- **RPM digests.** Every RPM row runs `rpm -K` and installs with the distribution's default
  `_pkgverify_level` (`digest` on rpm 4.19+). The RHEL 10 row repeats the install with the FIPS
  crypto-policy set.
- **Cost.** Sixteen jobs run on PRs in the `packaging=` path class and on `main`, with
  concurrency cancellation. Other PRs skip the matrix, and `github-release` needs it.

Decompose adds one **testing issue per capability** for claims left without a proof row. They are
blocked by S15 and S10 respectively.

## Constraints

- **Invariant 11 / ADR-0043.** The Relay reads its floor itself and checks the property on the
  descriptor it reads from. `/etc/relay` and the file are root's, and the unit has no
  capabilities. The check refuses a writable file anyway, so the property also holds off the
  packaged layout, and no test build can switch it off (Q11). Secrets never reach the
  environment or argv. Reload re-applies the check first.
- **Invariant 8.** The join string is a `/proto` message, first in the sequence.
- **Invariant 6 / ADR-0005, 0006, 0031.** The daemon still refuses an untrusted Relay, and the
  pin carries the trust anchor's integrity. Decision 4 is built as written: the address is
  persisted and `RELAY_ADDR` overrides it. `Enroll` stays the one certless RPC.
- **Invariant 1.** No wire input reaches `join`'s spawn: the argv is a literal and no shell runs.
  The clippy ban keeps holding every other site, and `clippy_write_ban.rs`'s existing censuses are
  widened to exactly two sanctioned sites (Q10). Maintainer scripts are host packaging, not Operations. The catalog ledger stops
  an upgrade from changing what an allowed Template name runs (ADR-0021 as amended).
- **Invariant 2.** Nothing writes a live Policy after first placement. `join` writes only the
  environment file.
- **Invariant 10.** Configuration has no adapter writer. The provider is a constructor input to
  the layer, and no surface can reach it.
- **Invariant 14 / ADR-0014.** Packages are release attachments the customer's tooling installs.
- **ADR-0030.** The binary loses two verbs and gains one. The ADR's account of `init`'s acts
  needs the owner's amendment (Q9).
- **ADR-0033 (all amendments).** No `curl | sh`, no hosted repository, no package signature;
  enable but never start; first-install-only placement; purge semantics; one unit per binary at
  `/usr/bin`.
- **ADR-0022 as amended.** The exact-path denies are added. The drop-in residual is unchanged.

## Rejected

- **`dpkg-deb` + `rpmbuild`.** `rpmbuild` post-processes binaries, and we need byte-for-byte.
- **fpm.** Ruby in the release path, and weaker reproducibility controls.
- **Conffile / `%config(noreplace)`.** Withdrawn by ADR-0033.
- **A hand-written join string format.** Two parsers kept in step by test vectors alone.
- **Pinning the server leaf or SPKI.** The leaf rotates every fourteen days, and ADR-0031 chose
  CA DER.
- **An address read from the join string on every start (DI-10 as written).** Keeps the token
  load-bearing after enrollment.
- **Keeping the `127.0.0.1` address fallback.** It turns a missing setting into a silent dial
  to the wrong host.
- **systemd over D-Bus for `join`.** A heavy dependency tree in a root binary for one call (Q10).
- **A devharness-only bypass of the start check.** Does not cover the shippable binary, and puts
  a "start anyway" branch in a security check (Q11).
- **`openat2(RESOLVE_NO_SYMLINKS)` as the only symlink defence.** Container seccomp profiles can
  return `ENOSYS`, and it yields no ancestor descriptors to check. The per-component walk does
  both.
- **Building the join string in the API handler.** An adapter would be assembling enrollment
  material, which is the capability's job (invariant 10).
- **A path unit watching for the join string.** DI-25 forbids it.
- **Restarting on package upgrade.** Config management restarts.
- **`BurntSushi/toml`.** It reports unknown keys after decoding, and its errors embed source
  text.
- **Comparing the catalog with the previous tag only.** A withdrawn-then-re-added name would
  slip through.
- **Keeping `RELAY_*` for one release.** ADR-0043 decision 6.
- **Per-consumer reload hooks.** A dozen ad-hoc paths in security-surface packages.
- **Deleting every `envOr` blindly.** It would silently drop the Freeze lever's release reason.

## Risks

- **nfpm `.rpm` reproducibility.** Header ordering and build time must honour
  `SOURCE_DATE_EPOCH` and `mtime`. If they cannot, that is a stop-and-escalate, not a reason to
  drop the comparison.
- **rpmpack's header digests.** nfpm's `.rpm` writer may emit only MD5/SHA1 header digests. rpm
  4.19+ (RHEL 10, Fedora) under `_pkgverify_level digest`, and any host in FIPS mode, may refuse
  such a package. A platform that refuses is unsupported under DI-33, so this would remove
  platforms rather than fail quietly. S15's `rpm -K` and FIPS rows detect it before release. If
  they fail, the step escalates: an nfpm/rpmpack version that writes SHA-256 header digests, or
  the owner decides.
- **systemd in containers** is not the real sandbox. The matrix proves package behaviour and the
  VM trace proves the unit.
- **Composition-root churn.** S9a deletes about 30 flags. Keeping `newServer(Config)` fixed
  bounds it.
- **Developer friction.** Running the shippable Relay by hand from a home directory is refused
  by design. Local runs go through the dev fleet, and real-binary tests need passwordless sudo
  or skip. On macOS, and on Docker Desktop's virtiofs/9p mounts, the filesystem allowlist
  refuses, so the dev fleet must mount from a Linux filesystem. S16 checks this.
- **CI cost.** Sixteen matrix jobs gate every release and every packaging PR.
- **Images.** Ubuntu 26.04 and UBI 10 must exist on both architectures. A missing image means an
  unsupported platform (DI-33), not a workaround.
